## Implementation approach

We will use Flask for the web application framework to handle routing and rendering. For data persistence, we'll leverage local storage using the browser's localStorage API via JavaScript. This avoids the complexity of setting up a database for such a simple application. The UI will be built with HTML, CSS, and JavaScript, focusing on a mobile-first, responsive design. We'll use vanilla JavaScript to minimize dependencies and keep the application lightweight. The main challenge will be managing the state of the todo list in the browser and ensuring smooth updates to the UI when tasks are added, deleted, or marked as complete.

## Program call flow


sequenceDiagram
    participant B as Browser
    participant WA as WebApp
    participant TL as TodoList
    participant TI as TodoItem

    B->>WA: GET / (initial load)
    WA->>TL: __init__()
    WA->>B: Render index.html with TodoList data

    B->>WA: POST /add_task (add new task)
    WA->>TL: add_item(text)
    TL->>TI: __init__(text)
    TL->>B: Return updated TodoList data (JSON)
    B->>B: Update UI

    B->>WA: POST /delete_task/id (delete task)
    WA->>TL: delete_item(id)
    TL->>B: Return updated TodoList data (JSON)
    B->>B: Update UI

    B->>WA: POST /complete_task/id (complete task)
    WA->>TL: complete_item(id)
    TL->>TI: set_completed(true)
    TL->>B: Return updated TodoList data (JSON)
    B->>B: Update UI

    B->>WA: GET /get_tasks (get all tasks)
    WA->>TL: get_all_items()
    TL->>TI: to_dict() (for each item)
    WA->>B: Return TodoList data (JSON)
    B->>B: Update UI

    loop Persisted Data
        B->>B: localStorage.setItem(TodoList data)
        B->>B: localStorage.getItem(TodoList data)
    end
